# AfforDigital

Website for AfforDigital: digital invitations and event pages for celebrations and corporate events (UAE).

- `index.html` – the full site: packages, corporate attendee registration, 15-second teaser, live sample invitations (wedding, 1st birthday, engagement, baby shower, corporate, anniversary), order form.
- `teaser.mp4`, `poster.jpg`, `logo.jpg` – media used by the page.

Static site, no build step. Deploys as-is on Vercel.
